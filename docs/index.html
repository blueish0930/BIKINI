Unofficial · Blender 5.3 Alpha · Windows x64

BIKINI

自用 / 实验向的 Blender 自定义构建：在主线之上推进 Geometry Nodes、 稀疏线性代数、 Image Process（COP） 与节点编辑器体验，并随 daily / main 同步。

Release Notes 更新日志 GitHub 仓库 下载 ZIP

Geometry Nodes

Portal、Clip、Loop 细分、K-Nearest、SDF Grid 等生产向节点扩展。

Math & Solver

Mesh Laplacian（COO）→ Linear Solver；Eigen + Spectra 稀疏求解与特征分解。

Image Process · COP

专用图像节点树：Stamp、Bake、法线↔高度、Fluid Zone 等。

UX & Shaders

节点组接口、抖动拆线、U 对齐；IQ 风格 SDF / Fractal 着色器。

开发目标

  • 跟主线，不 fork 成死支 — 基于 Blender 5.3 Alpha / main，持续合入上游。
  • 几何节点为中枢 — 把「能算的」搬进节点图：稀疏矩阵、拉普拉斯、线性系统、特征。
  • 图像节点独立成编辑器 — Image Process 作为 COP 向工作流，服务贴图 / 点云栅格 / 烘焙。
  • 体验优先 — 少拉线、好对齐、接口可说明、属性可读（含 String）。
  • 便携分发 — Windows x64 解压即用；文档与二进制同仓，便于自测与分享。
