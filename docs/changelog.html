BIKINI: Geometry Nodes & UX

Custom features on top of Blender 5.3 Alpha, documented in the same style as the official Geometry Nodes release notes. Source list: Achieve List; verified against this portable build (blender.exe + 5.3/scripts/startup/bl_ui/node_add_menu_*.py).

String Attributes

Geometry attributes support a String data type across the attribute pipeline. This enables text-like data on points, faces, and other domains, with UI and spreadsheet support.

  • Named Attribute / Store Named Attribute / Capture Attribute — string domain support
  • Viewer — string values in the viewer and improved viewport attribute text overlays
  • Join Geometry / Realize Instances — string attributes propagate correctly
  • Spreadsheet — columns can be sorted (click column header)

Geometry Nodes

Named Portal

The Named Portal node (GeometryNodeNamedPortal) passes values by name across a node tree, similar to a lightweight global link without long noodle runs.

Geometry Clip

The Geometry Clip node clips geometry against a plane or volume-style cut. Mesh classification and edge topology build have been optimized for large meshes.

Loop Subdivision

The Loop Subdivision node applies Loop subdivision to meshes.

Nearest Neighbours

The K-Nearest node (GeometryNodeKNearest) finds nearest neighbours for points / samples, useful for smoothing, clustering, and field sampling patterns.

Set Default Closure

The Set Default Closure node assigns a default closure to a closure socket when no external closure is connected.

Debug

The Debug node inspects intermediate geometry / values while authoring node trees.

Time Shift

The Time Shift node offsets evaluation time for downstream nodes.

Simulation cache
When used with a Simulation Zone, scrub to frame 1 (or otherwise reset the simulation cache) after structural changes. This is native Blender simulation cache behaviour.

Object Info — Seed

Object Info exposes a Seed control for deterministic randomness / instance variation tied to object info sampling.

Menu Switch — multi-select

Menu Switch supports multi-selection of menu items for richer branching UIs.

Math & Solver

A sparse linear-algebra path for geometry-driven problems (smoothing, diffusion, pin-and-solve, eigensystems).

  • Mesh Laplacian — builds a mesh Laplacian as a sparse matrix bundle (uniform / cotangent-style modes; I+tL / mass-matrix variants where applicable)
  • Sparse Matrix Math — add / multiply / combine sparse matrix bundles (COO-style), with sync helpers for bundle layouts
  • Linear Solver — solve Ax = b, optional pin constraints, matrix factorization, and partial eigen decomposition (sparse path; Eigen / Spectra)

Zones

  • Repeat Zone — Break — boolean early-exit on the zone output so the loop can stop before reaching the iteration count
  • Simulation Zone — Cache Limit — cap how many frames of simulation cache are retained, reducing unbounded memory growth

Node Group Interface

  • Separator and Message items — organize group inputs/outputs with visual dividers and help text (same spirit as panel layout polish in mainline)
  • Join to Next Parameter — place the next socket on the same row to save vertical space
  • Ctrl + LMB rename — rename group interface sockets from the node header area, with hover highlight feedback
  • Enable Input / Output — when disabled, the interface is hidden, external links are ignored, and outputs fall back to static defaults / Default Input

Node Editor UX

  • Shake to detach — shaking a node detaches it from links; supports inserting multiple nodes along a chain in one gesture flow
  • Hold U + drag — hold U while dragging with LMB to align nodes horizontally or vertically
  • Viewport attribute overlay — clearer attribute / viewer text overlays in the 3D View
  • Spreadsheet column sort — click headers to sort attribute columns

Image Process

An Image Process node tree (COPs-oriented workflow) for point/image operations outside the classic compositor-only path. Registered under Image Process add menus.

  • Import Points / Rasterize Geometry — bring geometry samples into image space
  • Point Stamp — stamp points into an image; tiled parallel rasterization for dense clouds
  • Normal to Height / Height to Normal — convert between normal maps and height maps
  • Bake Image (2026-07-29) — multi-format bake (PNG, JPEG, EXR, TIFF, BMP, Targa, WebP, HDR), color space, Path / Name string sockets, top-level Bake button; Bundle item naming for stamp maps
  • Get / Store Bundle Item — Image Process Utilities › Bundle (compositor lookup for stamp maps)

Disabled / Not shipped

  • Viewport Camera node Disabled — present in development notes / Achieve List as //viewport camera; not enabled in this portable build (not registered in add menus; not linked in blender.exe).

Known Issues

  • Time Shift + Simulation Zone: after graph changes, return to the first frame (or clear simulation cache) so cached frames do not show stale results. This is upstream cache behaviour.
  • This is an unofficial custom build and is not digitally signed by the Blender Foundation.
