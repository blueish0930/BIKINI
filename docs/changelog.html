BIKINI 5.3: Geometry Nodes

Custom geometry nodes and related workflows. Layout modelled on Blender 5.3 Geometry Nodes notes.

自定义几何节点与相关工作流。版式参考 Blender 5.3 Geometry Nodes 说明。

Attributes属性

  • String attributes are supported end-to-end (Named Attribute, Store Named Attribute, Capture Attribute, Viewer, geometry propagation, and spreadsheet columns).
  • String 属性全链路支持 （Named Attribute、Store Named Attribute、Capture Attribute、Viewer、 几何传递与电子表格列）。

Portal & Clip

  • Named Portal / Store Named Portal — pass values by name across a node tree without long noodle runs.
  • Geometry Clip — clip geometry against a plane / cut.
  • Named Portal / Store Named Portal — 按名称在节点树中传值，避免长距离拉线。
  • Geometry Clip — 按平面或裁切几何。

Closures闭包

  • Set Default Closure — specify a default closure when no external closure is connected.
  • Set Default Closure — 未连接外部闭包时设置默认闭包。

Subdivision细分

  • Loop Subdivision — classic Loop subdivision for triangle meshes.
  • Loop Subdivision — 三角网格的经典 Loop 细分。

Nearest neighbours最近邻

  • K-Nearest — find nearest neighbours for points / samples (smoothing, clustering, field sampling).
  • K-Nearest — 点 / 采样的最近邻查询（平滑、聚类、场采样）。

Debug & time调试与时间

  • Debug — inspect intermediate geometry / values while authoring.
  • Time Shift — offset evaluation time for downstream nodes. With a Simulation Zone, return to frame 1 (or reset cache) after structural changes (native Blender cache behaviour).
  • Object Info → Seed — deterministic randomness / instance variation.
  • Debug — 编写时检查中间几何 / 数值。
  • Time Shift — 为下游偏移求值时间。 与模拟区联用时，结构改动后需回到第一帧重置 cache（原生行为）。
  • Object Info → Seed — 确定性随机 / 实例变化。

Select & edit选择与编辑

  • Select Elements — domain selection helpers (points / edges / faces) and field-driven masks.
  • Edit Elements — temporarily enter free Mesh Edit Mode on the cooked upstream result; store the full edited mesh back on the node (with Reset).
  • Select Elements — 域选择（点 / 边 / 面）与场驱动遮罩。
  • Edit Elements — 对上游结果临时进入自由 Mesh Edit Mode， 将完整编辑结果存回节点（含 Reset）。

Geodesic, remesh & fracture 测地线、重拓扑与破碎

  • Heat Geodesic — approximate surface distance from selected sources via the heat method.
  • Instant Meshes — field-aligned remeshing (quad or triangle output).
  • QuadWild — remesh / field / layout stages (QRemeshify pipeline).
  • Triangle Remesh — isotropic remeshing (uniform or curvature-adaptive).
  • Voronoi Fracture — fracture from point / vertex sites (Voro++ neighbour planes, half-space clipping).
  • Heat Geodesic — 热方法近似曲面测地距离。
  • Instant Meshes — 场对齐重拓扑（四边形或三角形输出）。
  • QuadWild — Remesh / Field / Layout 三阶段（QRemeshify 管线）。
  • Triangle Remesh — 各向同性三角重拓扑（均匀或曲率自适应）。
  • Voronoi Fracture — 点 / 顶点站点破碎（Voro++ 邻接平面、半空间裁切）。

Graph coloring & fields 图染色与场

  • Mesh Graph Coloring — color the vertex 1-ring graph so adjacent vertices get different integer IDs.
  • Tangent Field — smooth N-RoSy tangent field on the mesh.
  • Gradient / Divergence — differential operators on scalar / vector fields.
  • Curve Intersection — detect / sample curve intersections.
  • Mesh Graph Coloring — 顶点一环邻接图染色，相邻顶点不同整数 ID。
  • Tangent Field — 平滑 N-RoSy 切向场。
  • Gradient / Divergence — 标量 / 向量场微分算子。
  • Curve Intersection — 曲线相交检测 / 采样。

Field write & sample 场写入与采样

  • Write at Index — scatter a field into a target domain by Target Index (source and target domains may differ). Collisions merge with Atomic Operator: Sum / Min / Max / Mean. Data Type: Float / Integer / Vector.
  • RBF Interpolate — fit a radial-basis interpolant through Source sample Values so f(xᵢ)=vᵢ exactly (solves Φw=v, not a kernel-weighted average), then evaluate on Sample Position. Kernel panel: Type (Gaussian, Inverse Multiquadric, Linear, Cubic, Quintic, Wendland C2) and Size. Menu: Geometry → Sample. Dense solve; n ≤ 4096.
  • Write at Index — 按 Target Index 将场 scatter 写入目标域 （源/目标域可不同）。冲突用 Atomic Operator 归并：Sum / Min / Max / Mean。 Data Type：Float / Integer / Vector。
  • RBF Interpolate — 从 Source 采样点 Value 拟合径向基插值， 采样点精确还原 f(xᵢ)=vᵢ（解 Φw=v，非核加权平均）， 在 Sample Position 上求值。Kernel 面板：Type （Gaussian / Inverse Multiquadric / Linear / Cubic / Quintic / Wendland C2）与 Size。 菜单：Geometry → Sample。稠密求解；n ≤ 4096。

表达式Expression

  • Expression — evaluate a typed expression string on field / socket inputs, with autocomplete for identifiers, functions, and syntax.
  • Expression — 对场 / 接口输入求值类型化表达式， 支持标识符、函数与语法的自动补全。

Sparse matrix math 稀疏矩阵数学

Geometry Nodes path for sparse linear algebra on meshes. Backend: Eigen + Spectra. (A dedicated Solver / physics category will come later when true physics solvers land.)

几何节点内的稀疏线性代数路径。后端：Eigen + Spectra。 （真正的物理 Solver 分类会在后续物理求解器落地后再单独开栏。）

Mesh → Mesh Laplacian → [Sparse Matrix Math] → Linear Solver

  • Mesh Laplacian — discrete mesh Laplacian as a sparse COO bundle (weight / row / col). Modes: Uniform, Cotangent; optional diffusion / mass.
  • Sparse Matrix Math — add / multiply / combine sparse matrix bundles.
  • Linear Solver — solve Ax = b, factor, multiply, or partial eigenpairs on sparse matrices (optional pin constraints).
  • Mesh Laplacian — 离散网格拉普拉斯，稀疏 COO Bundle （weight / row / col）。模式：Uniform、Cotangent；可选扩散 / 质量。
  • Sparse Matrix Math — 稀疏矩阵 Bundle 加减乘组合。
  • Linear Solver — 在稀疏矩阵上求解 Ax = b、分解、乘积或部分特征对 （可选钉约束）。

Simulation cache 模拟缓存

Time Shift + Simulation Zone: scrub to frame 1 (or reset the simulation cache) after structural changes.

Time Shift 与模拟区：结构改动后请回到第 1 帧（或重置模拟缓存）。

v2: Geometry Nodesv2：几何节点

Group / Guide / Transfer组 / 引导 / 传递

  • Set Group Input Default (GeometryNodeSetGroupInputDefault) — When the matching group input is not linked outside the group, every Group Input node in this tree returns Default for that socket
  • Guide Geometry (GeometryNodeGuideGeometry) — Draw extra geometry in the 3D Viewport while the object is selected. Hidden when the modifier is disabled. Does not affect render or the modifier output, and is not shown in the Spreadsheet
  • Attribute Transfer (GeometryNodeAttributeTransfer) — Sample a point-domain field by kernel-weighted sum of all neighbors inside Smooth Distance. Weighted kernels keep distance falloff (not averaged)
  • Optimal Transport (GeometryNodeCgalOptimalTransport) — One-to-one match Source points onto Target by min total squared distance (discrete optimal transport / assignment). Outputs the original Source plus an anonymous Target Index attribute. Extra source points get -1 when Source has more points than Target.
  • Make It Stand (GeometryNodeMakeItStand) — Make It Stand (SIGGRAPH 2013): carve the heavy-side interior, then Laplacian-deform so the center of mass projects onto the landing. Not smoothing, not base-scale.
  • Get Vector Component (FunctionNodeGetVectorComponent) — Get the X, Y or Z component of a vector by index
  • Set Vector Component (FunctionNodeSetVectorComponent) — Set the X, Y or Z component of a vector by index
  • Get Matrix Component (FunctionNodeGetMatrixComponent) — Get a 4x4 matrix component by column and row index
  • Set Matrix Component (FunctionNodeSetMatrixComponent) — Set a 4x4 matrix component by column and row index
  • 设置组输入默认值（GeometryNodeSetGroupInputDefault）— 当对应的组输入在组外未连接时，此节点树中每个组输入节点对该接口返回默认值
  • 引导几何体（GeometryNodeGuideGeometry）— 物体选中时在 3D 视图中绘制额外几何。修改器禁用时隐藏。不影响渲染或修改器输出，也不出现在电子表格中
  • 属性传递（GeometryNodeAttributeTransfer）— 用平滑距离内所有邻居的核加权和对点域场采样。带权核保留距离衰减（不取平均）
  • 最优传输（GeometryNodeCgalOptimalTransport）— 按总平方距离最小，将源点与目标点一一匹配（离散最优传输 / 指派）。输出原始源几何，并附带匿名「目标索引」属性。源点多于目标点时，多出的源点索引为 -1。
  • 使其站立（GeometryNodeMakeItStand）— 使其站立（SIGGRAPH 2013）：掏空偏重一侧内部，再拉普拉斯变形，使质心投影落到支撑面上。不是平滑，也不是缩放底座。
  • 获取矢量分量（FunctionNodeGetVectorComponent）— 按索引获取矢量的 X、Y 或 Z 分量
  • 设置矢量分量（FunctionNodeSetVectorComponent）— 按索引设置矢量的 X、Y 或 Z 分量
  • 获取矩阵分量（FunctionNodeGetMatrixComponent）— 按列、行索引获取 4×4 矩阵分量
  • 设置矩阵分量（FunctionNodeSetMatrixComponent）— 按列、行索引设置 4×4 矩阵分量

Box2D / Box3D

Achieve List「Box2D/3D」：Box 引擎 为 2D（Box2D），Jolt 为 3D 刚体。

Box Engine is the 2D (Box2D) path; Jolt is the 3D rigid-body path.

Box EngineBox 引擎

  • Box Set Rigid Body — Body type + collision shape for Box Engine. Mesh-based modes need no Size. Collision output shows the actual collider (hull / island hulls / triangle mesh)
  • Box Set Constraint — Add one Box Engine joint. Distance/Weld/Prismatic take two named bodies. Revolute hinges Body A to a world Anchor
  • Box Solver — Step Box2D/Box3D rigid bodies. Static/Kinematic bodies on Geometry are obstacles. Substeps = collide slices this frame. Prefer Instances inside a Simulation Zone
  • Box 设置刚体 — Box 引擎的刚体类型 + 碰撞形状。基于网格的模式不需要尺寸。碰撞输出显示实际碰撞体（凸包 / 岛凸包 / 三角网格）
  • Box 设置约束 — 添加一个 Box 引擎关节。距离/焊接/滑动副需要两个已命名刚体。转动副把刚体 A 铰到世界锚点
  • Box 求解器 — 步进 Box2D/Box3D 刚体。几何上的静态/运动学刚体是障碍。子步数 = 本帧碰撞切片数。建议在模拟区内使用实例

Jolt

  • Jolt Set Rigid Body — Body type + collision shape. Static bodies are colliders in Jolt Solver. Capsule/Cylinder are Z-up. Triangle Mesh is static (Dynamic uses a hull)
  • Jolt Set Constraint — Add one Jolt constraint (fixed, distance, point, hinge, cone, slider, swing-twist, six-DOF, path, gear, rack-and-pinion, pulley, vehicle). Plug into Jolt Solver
  • Jolt Solver — Black-box Jolt step from input geometry. Writes velocity, angular_velocity, acceleration, angular_acceleration, mass and inertia (I, not angular accel)
  • Jolt 设置刚体 — 刚体类型 + 碰撞形状。静态刚体在 Jolt 求解器中作为碰撞体。胶囊/圆柱为 Z 向上。三角网格为静态（动态改用凸包）
  • Jolt 设置约束 — 添加一个 Jolt 约束（固定、距离、点、铰链、锥、滑轨、摆动-扭转、六自由度、路径、齿轮、齿条齿轮、滑轮、载具）。接到 Jolt 求解器
  • Jolt 求解器 — 从输入几何做黑盒 Jolt 步进。写入 velocity、angular_velocity、acceleration、angular_acceleration、mass 和 inertia（I，不是角加速度）

v2: Texture / GPU Texture Editorv2：纹理 / GPU 纹理编辑器

  • Camera View (ImageNodeCameraView) — Viewport-style preview from a camera (Wireframe/Solid/Material/Rendered). Updates every frame when used; does not re-evaluate unrelated node branches
  • Island UV (ImageNodeIslandUV) — Each same-color connected island gets its own UV from that island's OBB. Origin: OBB center (0 at center) or bottom-left (0 at min). Fit 0-1 normalizes the island; Real Size keeps its size in the texture 0-1 UV
  • Island Padding (ImageNodeIslandPadding) — Expand island colors into empty pixels by sampling the nearest seed, clipped by Distance
  • Named Portal (CompositorNodeNamedPortal) — Read a value from a Store Named Portal in the current node tree
  • Store Named Portal (CompositorNodeStoreNamedPortal) — Publish a value under a unique name in the current node tree
  • FFT (ImageNodeFFT) — 2D FFT of a complex field packed as R = real, G = imaginary (row then column 1D FFTs)
  • Import Geo (ImageNodeImportGeo) — Nested Geometry Nodes under GPU Texture Editor (groups named COP-Import Geo[.N]; switchable among those groups only; no Group Input). Group Output: Geometry. Double-click to edit in-place. Connect to Rasterize Geometry
  • Geo SDF (ImageNodeGeoSDF) — Compute a per-pixel SDF on the 0–1 XY texture grid. 3D solids are sliced at z=0; closed contours are filled (signed), open curves and points are unsigned
  • Render Material (ImageNodeRenderMaterial) — Temporarily assign a material to a UV plane and render it to a color texture
  • ShaderToy (ImageNodeShaderToy) — Paste ShaderToy GLSL (Image / Common / Buffer A–D) in the sidebar, Compile, output Color
  • 摄像机视图（ImageNodeCameraView）— 摄像机视口风格预览（线框 / 实体 / 材质 / 渲染）。被使用时每帧更新；不会重算无关节点分支
  • 岛 UV（ImageNodeIslandUV）— 每个同色连通岛用该岛 OBB 得到自己的 UV。原点：OBB 中心（中心为 0）或左下（最小为 0）。适配 0-1 归一化该岛；真实尺寸保持它在纹理 0-1 UV 中的大小
  • 岛填充（ImageNodeIslandPadding）— 按最近种子把岛颜色扩展到空像素，受距离裁剪
  • 命名传送门（CompositorNodeNamedPortal）— 从当前节点树中的存储命名传送门读取值
  • 存储命名传送门（CompositorNodeStoreNamedPortal）— 在当前节点树中以唯一名称发布值
  • FFT（ImageNodeFFT）— 把复数场打成 R = 实部、G = 虚部后做二维 FFT（先按行再按列的一维 FFT）
  • 导入几何（ImageNodeImportGeo）— GPU 纹理编辑器下的嵌套几何节点（组名 COP-Import Geo[.N]；仅在这些组之间切换；无组输入）。组输出：几何。双击就地编辑。接到栅格化几何
  • 几何 SDF（ImageNodeGeoSDF）— 在 0–1 XY 纹理网格上逐像素计算 SDF。三维实体在 z=0 切片；闭合轮廓填充（有符号），开放曲线和点为无符号
  • 渲染材质（ImageNodeRenderMaterial）— 临时把材质赋给 UV 平面并渲染成颜色纹理
  • ShaderToy（ImageNodeShaderToy）— 在侧栏粘贴 ShaderToy GLSL（Image / Common / Buffer A–D），编译，输出颜色

v2: Object Editorv2：物体编辑器

新的 ObjectNodeTree：用节点图创建 / 引用物体、改变换与可见性、指定材质槽与修改器、设置父级或删除。默认图：Object → Set Transform → Object Output。

New ObjectNodeTree: create or pick objects, set transform/visibility, material slots, modifiers, parent, or delete. Default graph: Object → Set Transform → Object Output.

  • Object (ObjectNodeObject) — Pick an existing object, or use the view-layer active object
  • Create Object (ObjectNodeCreate) — Create a scene object (reused on recook). Connect to Object Output to instantiate
  • Object Output (ObjectNodeOutput) — Apply every connected object graph to the scene, like Join Geometry. All used inputs stay live; nodes that do not reach an Object Output are not written
  • Set Transform (ObjectNodeSetTransform) — Write location, rotation and scale of the incoming object
  • Set Visibility (ObjectNodeSetVisibility) — Set viewport, select and render visibility, holdout and shadow catcher
  • Viewport Display (ObjectNodeViewportDisplay) — Set object viewport display type, extras, bounds and object color
  • Set Material Slots (ObjectNodeSetMaterialSlots) — Assign object material slots. Add and remove slots like the Properties editor
  • Set Modifiers (ObjectNodeSetModifiers) — Edit the object's modifier stack. Expand a modifier to set Geometry Nodes groups, Subdivision levels, Apply, and the rest of its settings
  • Set Parent (ObjectNodeSetParent) — Bind or clear object parenting. Bind: Object / Object without inverse, with optional Keep Transform. Clear: Clear Parent, keep transform, or reset the parent inverse
  • Delete Object (ObjectNodeDelete) — Delete the incoming object from the scene when the graph is evaluated
  • 物体（ObjectNodeObject）— 选取已有物体，或使用视图层活动物体
  • 创建物体（ObjectNodeCreate）— 创建场景物体（重评估时复用）。接到物体输出才会实例化
  • 物体输出（ObjectNodeOutput）— 把所有连上的物体图应用到场景，类似合并几何。用到的输入保持有效；到不了物体输出的节点不会写入
  • 设置变换（ObjectNodeSetTransform）— 写入传入物体的位置、旋转和缩放
  • 设置可见性（ObjectNodeSetVisibility）— 设置视口 / 可选 / 渲染可见性，以及阻光与阴影捕捉
  • 视图显示（ObjectNodeViewportDisplay）— 设置物体视口显示类型、附加项、包围盒和物体颜色
  • 设置材质槽（ObjectNodeSetMaterialSlots）— 指定物体材质槽。可像属性编辑器一样增删槽
  • 设置修改器（ObjectNodeSetModifiers）— 编辑物体修改器栈。展开修改器可设置几何节点组、细分级别、应用及其它参数
  • 设置父级（ObjectNodeSetParent）— 绑定或清除物体父子。绑定：物体 / 物体（无反向），可选保持变换。清除：清除父级、保持变换，或重置父级反向
  • 删除物体（ObjectNodeDelete）— 图求值时从场景中删除传入物体
