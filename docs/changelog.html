Named Portal / Store Named Portal

Named Portal (GeometryNodeNamedPortal) and Store Named Portal pass values by name across a node tree — lightweight named links without long noodle runs.

Named Portal（GeometryNodeNamedPortal）与 Store Named Portal 按名称在节点树中传值， 轻量命名连接，避免长距离拉线。

Geometry Clip

Geometry Clip (GeometryNodeGeometryClip) clips geometry against a plane / cut. Mesh classification and edge topology build are optimised for large meshes.

Geometry Clip（GeometryNodeGeometryClip）按平面或裁切几何。 网格分类与边拓扑构建已针对大网格优化。

Loop Subdivision

Loop Subdivision (GeometryNodeLoopSubdivision) applies the classic Loop subdivision scheme to triangle meshes.

Loop Subdivision（GeometryNodeLoopSubdivision）对三角网格应用 经典 Loop 细分。

K-Nearest (Nearest Neighbours)

K-Nearest (GeometryNodeKNearest) finds nearest neighbours for points / samples — useful for smoothing, clustering, and field sampling patterns.

K-Nearest（GeometryNodeKNearest）为点 / 采样查找最近邻， 适用于平滑、聚类与场采样等。

Edit Elements

Edit Elements (GeometryNodeEditElements) lets a node temporarily enter free Mesh Edit Mode on the cooked upstream result. Press Enter to edit with normal mesh tools; Esc, Enter, or Tab stores the complete edited mesh back in the node. The node body shows the stored mesh status and provides a full-width Reset action.

Edit Elements（GeometryNodeEditElements）可对上游求值结果临时进入自由 Mesh Edit Mode。按 Enter 进入编辑，可使用常规网格工具；按 Esc、Enter 或 Tab 后，将完整编辑结果 存回节点。节点本体会显示已保存网格的状态，并提供醒目的 Reset 按钮。

Heat Geodesic

Heat Geodesic computes an approximate surface distance from selected source vertices with the heat method: short-time heat diffusion, a unit-gradient field, then a Poisson solve. It uses a cotangent Laplacian with t = mean edge length² and outputs a point-domain Distance field.

Heat Geodesic 使用热方法计算到选定源顶点的近似曲面测地距离：先做短时间热扩散， 再构造单位梯度场，最后求解 Poisson 方程。节点使用余切拉普拉斯与 t = 平均边长²，输出点域 Distance 场。

Remeshing tools重拓扑工具

  • Instant Meshes Official field-aligned core with Quad or Triangle output. Resolution can be Auto, Edge Length, Face Count, or Vertex Count; crease, boundary alignment, smoothing, and deterministic options are exposed on the node.
  • Triangle Remesh pmp-library Botsch–Kobbelt remeshing with Uniform or curvature-Adaptive sizing, feature protection, projection, and boundary preservation.
  • QuadWild QRemeshify/QuadWild pipeline with three node-socket modes: Remesh for pure quads, Field for 4-RoSy face attributes, and Layout for patch boundaries and optional UV seams.
  • Instant Meshes 集成官方 field-aligned 核心，可输出四边形或三角形。分辨率可按 Auto、Edge Length、Face Count 或 Vertex Count 控制，并在节点上提供折痕、边界对齐、平滑与确定性选项。
  • Triangle Remesh 基于 pmp-library 的 Botsch–Kobbelt 三角重拓扑，支持 Uniform 与曲率自适应尺寸，并可保护特征、投影回原表面及保留开放边界。
  • QuadWild 集成 QRemeshify/QuadWild 管线，节点 Mode 接口提供三阶段：Remesh 生成纯四边形；Field 输出 4-RoSy 面属性；Layout 输出 Patch 边界与可选 UV Seam。

Voronoi Fracture

Fractures a mesh from point-cloud or mesh-vertex sites. Exact sparse Voronoi neighbour planes come from Voro++; pieces are cut by half-space clipping rather than Blender mesh booleans. Inside optionally fills planar cut caps, while Gap shrinks each cell toward its site. Face attributes identify cell_index, inside, and outside.

使用点云或网格顶点作为站点对网格进行 Voronoi 破碎。Voro++ 提供精确、稀疏的邻接平面，碎片通过 半空间裁切生成，不依赖 Blender 网格布尔。Inside 可填充平面切口， Gap 可令每个单元向站点收缩；面属性记录 cell_index、inside 与 outside。

Mesh Graph Coloring

Colors the mesh vertex 1-ring graph so adjacent vertices receive different integer IDs. Choose Greedy, Greedy Random, Welsh–Powell, DSatur, or RLF; the result is stored as a named point attribute and Color Count reports the number of colors used.

对网格顶点的一环邻接图进行染色，使相邻顶点获得不同整数 ID。支持 Greedy、Greedy Random、 Welsh–Powell、DSatur 与 RLF；结果写入指定名称的点域整数属性，Color Count 输出实际使用的颜色数。

Tangent Field

Computes a smooth N-RoSy tangent field with the Directional power-field solver. Odd and even orders from 1 to 12 are supported. The N directions are written as point vector attributes named Prefix0 through Prefix{N-1}; mesh islands are solved separately.

使用 Directional power-field 求解器计算平滑 N-RoSy 切向场，支持 1 到 12 的奇数或偶数阶。 N 个方向分别写入 Prefix0 到 Prefix{N-1} 点域向量属性；不同网格岛独立求解。

Math & Solver 数学与求解器

A sparse linear-algebra path for geometry-driven problems: smoothing, diffusion, pin-and-solve, and partial eigensystems. Inspired by Houdini-style sparse workflows; implemented with Eigen and Spectra (not NumPy).

面向几何问题的稀疏线性代数路径：平滑、扩散、钉约束求解、部分特征系统。 交互语义参考 Houdini 稀疏工作流；后端为 Eigen 与 Spectra （不是 NumPy）。

Pipeline推荐链路

Mesh → Mesh Laplacian → [Sparse Matrix Math] → Linear Solver → x / eigenpairs
  1. Mesh Laplacian builds discrete Laplacian L (or diffusion / mass variants) as a sparse COO bundle.
  2. Sparse Matrix Math optionally adds / multiplies / combines sparse bundles.
  3. Linear Solver solves Ax = b, factors, multiplies, or computes eigenpairs on the sparse matrix.
  1. Mesh Laplacian 将离散拉普拉斯 L（或扩散 / 质量变体）建成稀疏 COO Bundle。
  2. Sparse Matrix Math 可选地做稀疏 Bundle 加减乘组合。
  3. Linear Solver 在稀疏矩阵上求解 Ax = b、分解、矩阵向量乘或特征对。

Mesh Laplacian

Mesh Laplacian (GeometryNodeMeshLaplacian) stores a discrete mesh Laplacian as a sparse matrix in COO format (Coordinate list): three equal-length lists packed into a typed Bundle.

Mesh Laplacian（GeometryNodeMeshLaplacian）将 离散网格拉普拉斯 存为 COO 格式稀疏矩阵 （Coordinate list）：三条等长列表打包进带类型的 Bundle。

COO layout COO 布局

Item项 Type类型 Meaning含义
weight float list Non-zero entry value A[i,j] 非零元数值 A[i,j]
row int list Row index of each non-zero 每个非零元的行索引
col int list Column index of each non-zero 每个非零元的列索引

Bundle type marker: FlatBundleType = Blender.SparseMatrix. Use Separate Bundle (+ Sync) to expose items. Only non-zeros are stored — memory is O(nnz), not O(n²).

Bundle 类型标记：FlatBundleType = Blender.SparseMatrix。 用 Separate Bundle（+ Sync）展开项。只存非零元 —— 内存为 O(nnz)，不是 O(n²)。

Weight modes & options 权重模式与选项

  • Uniform — graph Laplacian with equal weight −1 on each unique edge
  • Cotangent — cotangent Laplacian using opposite-angle cot weights on triangle edges (standard DDG / geometry processing form)
  • Diffusion Matrix — output I + tL (or M + tML when mass is on); t = Diffusion Coefficient
  • Use Mass — lumped mass M (face area / 3): without diffusion yields ML; with diffusion yields M + tML
  • Uniform — 图拉普拉斯，每条唯一边权 −1
  • Cotangent — 余切拉普拉斯，三角边上对顶角 cot 权重（常见 DDG / 几何处理形式）
  • Diffusion Matrix — 输出 I + tL（开质量时为 M + tML）；t = Diffusion Coefficient
  • Use Mass — 集中质量 M（面面积 / 3）：无扩散得 ML；有扩散得 M + tML

Input mesh is triangulated if needed before assembly. Typical uses: heat diffusion, biharmonic / as-rigid-as-possible style solves, spectral mesh processing (with Linear Solver eigen mode).

必要时会先三角化再装配。典型用途：热扩散、双调和 / ARAP 类求解、谱网格处理 （配合 Linear Solver 特征模式）。

Sparse Matrix Math

Sparse Matrix Math (GeometryNodeSparseMatrixMath) adds, multiplies, or otherwise combines sparse matrix bundles (COO-style), with helpers to keep Bundle layouts in sync for the solver pipeline.

Sparse Matrix Math（GeometryNodeSparseMatrixMath）对 COO 风格稀疏矩阵 Bundle 做加减乘等组合，并同步 Bundle 布局以便接入求解链路。

Linear Solver

Linear Solver (GeometryNodeLinearSolver) is the main consumer of sparse COO matrices. It introduces the Eigen (sparse direct / iterative linear algebra) and Spectra (partial eigen decomposition via mat-vec / shift-invert) math libraries into Geometry Nodes.

Linear Solver（GeometryNodeLinearSolver）是稀疏 COO 矩阵的主要消费端。 将 Eigen（稀疏直接法 / 迭代线性代数）与 Spectra（基于 mat-vec / shift-invert 的部分特征分解）数学库引入几何节点。

Libraries & algorithms 库与算法

Library库 Role职责 Notes说明
Eigen Sparse matrices, direct & iterative solvers 稀疏矩阵、直接与迭代求解 SimplicialLLT/LDLT, SparseLU, SparseQR; CG, GMRES, BiCGSTAB, … Path stays sparse (COO → Eigen::SparseMatrix) SimplicialLLT/LDLT、SparseLU、SparseQR；CG、GMRES、BiCGSTAB 等。全程稀疏（COO → Eigen::SparseMatrix）

UI / mode layout is intentionally close to Houdini sparse solver workflows (Solve / Decompose / Solve with Decomposition / Multiply). Not a NumPy / SciPy port.

UI 与模式划分有意贴近 Houdini 稀疏求解工作流 （Solve / Decompose / Solve with Decomposition / Multiply）。不是 NumPy / SciPy 移植。

Mode模式 What it does作用

Direct / Iterative methods 直接法 / 迭代法

  • Direct: LLT, LDLT, LU, QR (sparse Eigen factorizations)
  • Iterative: GMRES, DGMRES, MINRES, CG, LSCG, BiCGSTAB, IDRS
  • Preconditioners: Identity, Diagonal, IncompleteLUT, IncompleteCholesky
  • 直接法：LLT、LDLT、LU、QR（Eigen 稀疏分解）
  • 迭代法：GMRES、DGMRES、MINRES、CG、LSCG、BiCGSTAB、IDRS
  • 预条件：Identity、Diagonal、IncompleteLUT、IncompleteCholesky

For Laplacian / smoothing systems (SPD-ish): prefer Direct + LLT/LDLT, or Iterative + CG + Diagonal. Decompose once, then multiple Solve-with-Decomposition for different right-hand sides.

拉普拉斯 / 平滑类（近似 SPD）：优先 Direct + LLT/LDLT， 或 Iterative + CG + Diagonal。可先 Decompose 一次，再多次 Solve-with-Decomposition 换右端项。

Eigen / shift-invert 特征分解 / shift-invert

Spectra solves partial eigenproblems. Shift-invert targets eigenvalues near a shift σ by working on (A − σI)⁻¹ (largest magnitude of the inverse eigenvalue maps to closest-to-σ of A). Results are ordered by |λ − σ| ascending (near → far); increasing k only appends farther pairs without reshuffling earlier ones. Eigenvector signs are normalised (largest-magnitude component > 0). Full dense spectrum is only allowed for tiny n ≤ 512 as a fallback.

Spectra 做部分特征问题。Shift-invert 通过 (A − σI)⁻¹ 寻找靠近移位 σ 的特征值（逆特征值模最大 ⇔ 原矩阵最接近 σ）。输出按 |λ − σ| 升序（近→远）；增大 k 只在后面追加更远对， 不打乱前面结果。特征向量做符号规范化（最大模分量 > 0）。全谱 dense 仅在 n ≤ 512 时作为回退。

Performance rule
性能原则
Stay sparse end-to-end. Do not densify COO into an n×n matrix for large meshes — that path was removed after causing multi-hundred-MB spikes and cubic solve cost. 端到端保持稀疏。不要把 COO densify 成 n×n 稠密矩阵再求解 —— 大网格上会导致数百 MB 内存尖峰与三次方时间；该路径已移除。

Image Process (COP)

Image Process is a new dedicated node editor / tree type (ImageNodeTree) for image-centric graphs — analogous in spirit to Houdini COPs (Compositing Operators): a place to process pictures, stamps, height/normal maps, and bake results without forcing the classic scene-compositor workflow.

Image Process 是新的专用节点编辑器 / 节点树类型 （ImageNodeTree），面向图像处理图 —— 精神上接近 Houdini COPs（Compositing Operators）：专门处理图片、盖章、高度/法线、烘焙结果等， 而不必走经典场景合成器工作流。

Editor 编辑器

  • UI name: Image Process; RNA: ImageNodeTree
  • Description (internal): GPU-accelerated image processing node graph (compositor-style filters and transforms)
  • Add menus: node_add_menu_image.py — reuses many compositor colour / filter / transform ops, plus Image-only nodes
  • Asset catalog prefix: Image Process
  • Distinct from CompositorNodeTree registration (MVP split in node_image_tree.cc)
  • 界面名称：Image Process；RNA：ImageNodeTree
  • 内部说明：GPU 加速的图像处理节点图（合成器风格滤镜与变换）
  • 添加菜单：node_add_menu_image.py — 复用大量合成器色彩 / 滤镜 / 变换，并含 Image 专有节点
  • 资产目录前缀：Image Process
  • 与 CompositorNodeTree 注册分离（node_image_tree.cc 中的 MVP 拆分）

Key nodes 核心节点

  • Point Stamp (ImageNodePointStamp) — stamp points into an image; tiled parallel rasterization for dense clouds
  • Normal to Height / Height to Normal — convert between normal maps and height maps

  • SDF Shape / Fractal Primitive — Image-only path (ImageNodeSDFShape / ImageNodeFractalPrimitive), not the Shader variants (menu fixed 2026-07-30)
  • Get / Store Bundle Item (+ Combine / Join / Separate Bundle) — Utilities › Bundle for stamp maps and multi-slot bakes
  • Viewer / File Output — Image Process I/O
  • Import Points / Rasterize Geometry — 将几何采样导入图像空间
  • Point Stamp（ImageNodePointStamp）— 点盖章到图像；分块并行栅格化，适合稠密点云
  • Normal to Height / Height to Normal — 法线贴图与高度图互转
