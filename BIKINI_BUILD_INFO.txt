How to use
----------
1. Extract the ZIP as a whole folder (do not copy blender.exe alone).
2. Run blender.exe inside this folder.
3. Keep these next to blender.exe: 5.3\, blender.crt\, blender.shared\,
   license\, python3.dll, python313.dll, bf_intern_*.dll, quadwild\.
